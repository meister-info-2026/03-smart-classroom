## 1단계. 저장소 Clone 및 로컬 개발 환경 준비 (팀당 1회)

### 1-1. 저장소 받기 (`classroom` 브랜치)
PowerShell에서 아래 명령어를 실행하여 1차가 완성된 `classroom` 브랜치를 클론합니다:
```powershell
git clone -b classroom https://github.com/foxjini/agent-vibe-coding-starter-kit2.git iot-classroom
cd iot-classroom
```
*(Git이 익숙하지 않다면 GitHub 웹페이지에서 `classroom` 브랜치를 선택한 후 **Code → Download ZIP**으로 받아 압축을 해제해도 됩니다.)*

### 1-2. Antigravity IDE 열기 및 Rules 3개 설정
Antigravity IDE에서 `iot-classroom` 폴더를 워크스페이스로 엽니다.  
상단 "…" 메뉴 → **Customizations** 패널 → **Rules**에서 아래 **3개만 "Always On"**으로 켭니다:
- `karpathy-principles` (모든 작업의 기본 4원칙)
- `security-rules` (시크릿 보호 원칙)
- `coding-standards` (코드 품질 표준)

> ⚠️ **토큰 절약 필수**: 나머지 7개 규칙은 각 에이전트(`agent.md`)가 호출될 때 자동으로 로드됩니다. 10개를 전부 Always On으로 켜면 매 프롬프트마다 8,000~12,000 토큰이 낭비되므로 반드시 위 3개만 켜둡니다.

### 1-3. 환경변수 파일(`.env`) 4개 생성
프로젝트 루트에서 각 폴더의 `.env.example`을 복사하여 `.env`를 만듭니다:
```powershell
copy backend\.env.example backend\.env
copy frontend\.env.example frontend\.env
copy vision\.env.example vision\.env
copy pi\.env.example pi\.env
```
> 💡 **보안 주의**: `backend/.env`, `vision/.env`, `pi/.env`의 `DEVICE_API_KEY`는 서로 일치해야 정상 인증됩니다. 팀 전용 비밀 키(예: `classroom_secret_2026`)를 정해 세 파일에 동일하게 채워 넣으세요.

### 1-4. 영역별 의존성 패키지 설치 (학생 직접 실행)
프로젝트 코드가 이미 준비되어 있으므로, 패키지 설치만 순서대로 진행합니다.

> ⚠️ **[필수 주의사항 - Python 버전 및 인코딩]**  
> 1. **Python 버전**: PC에 여러 파이썬 버전(Python 3.14 등)이 있거나 기본값이 다를 수 있으므로, 딥러닝/영상인식 라이브러리(onnxruntime, opencv 등)의 바이너리 호환성을 위해 **반드시 `py -3.12 -m venv venv`**를 사용하여 Python 3.12 가상환경을 생성해야 합니다. (Python 3.14는 라이브러리 미지원으로 사용 불가)  
> 2. **Windows 인코딩 오류 방지**: Windows 기본 콘솔 인코딩(cp949)으로 인한 설치 에러(`UnicodeDecodeError`)를 방지하기 위해 **반드시 `$env:PYTHONUTF8=1; pip install -r requirements.txt`**를 사용해 패키지를 설치해야 합니다.

#### ① 백엔드 (Python 3.12 가상환경 및 라이브러리 설치)
```powershell
cd backend
py -3.12 -m venv venv
.\venv\Scripts\Activate.ps1
$env:PYTHONUTF8=1; pip install -r requirements.txt
cd ..
```
*(PowerShell 스크립트 실행 오류 발생 시: `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser` 실행)*

#### ② 프론트엔드 (Next.js 패키지 설치)
Next.js 스캐폴드와 대시보드 컴포넌트(`SeatMap.tsx`, `ActuatorCard.tsx` 등)가 이미 구축되어 있습니다. `npm install`만 실행합니다:
```powershell
cd frontend
npm install
cd ..
```

#### ③ 비전 (Python 3.12 가상환경 및 영상인식 라이브러리 설치)
Windows 환경의 C++ DLL 충돌 방지 및 ONNX 엔진 호환성을 위해 **반드시 Python 3.12** 가상환경을 사용합니다 (`vision/yolov8n.pt` 가중치는 이미 내장되어 있습니다):
```powershell
cd vision
py -3.12 -m venv venv
.\venv\Scripts\Activate.ps1
$env:PYTHONUTF8=1; pip install -r requirements.txt
cd ..
```

## 2단계. 1차 완성 시스템 로컬 구동 및 동작 확인 (멀티 터미널)

2차 개발을 진행하기 전, 1차 완성 베이스라인이 내 PC에서 정상 작동하는지 확인합니다.  
스마트 교실 시스템은 3개 프로세스가 실시간으로 통신하므로 **터미널을 3개 열어 동시에 실행**합니다.

```
┌─────────────────────────────────┐   WebSocket / REST    ┌─────────────────────────────────┐
│     터미널 1: 백엔드 (포트 8000)   │ ◄──────────────────► │    터미널 2: 프론트엔드 (포트 3000) │
│     FastAPI + MySQL (MariaDB)   │                      │    Next.js 6석 인터랙티브 대시보드 │
└─────────────────────────────────┘                      └─────────────────────────────────┘
                 ▲
                 │ POST /api/v1/vision/events
┌─────────────────────────────────┐
│     터미널 3: 비전 클라이언트    │
│     YOLOv8 사람/좌석 감지       │
└─────────────────────────────────┘
```

### 2-1. DB 초기화 (XAMPP MySQL 실행)
1. **XAMPP Control Panel**을 열고 **MySQL(MariaDB)**의 `Start` 버튼을 누릅니다.
2. 새 PowerShell 창에서 `backend/db/init.sql`을 실행해 10종 디바이스 시드와 테이블을 등록합니다:
```powershell
cd backend
Get-Content db\init.sql | mysql -u root
cd ..
```
*(mysql 명령어가 인식되지 않으면 phpMyAdmin 웹 UI `http://localhost/phpmyadmin`의 [SQL] 탭에 `backend/db/init.sql` 내용을 붙여넣고 실행해도 됩니다.)*

### 2-2. 터미널 1: 백엔드 서버 구동
```powershell
# [터미널 1]
cd backend
.\venv\Scripts\Activate.ps1
uvicorn main:app --reload --port 8000
```
- **확인**: 브라우저에서 `http://localhost:8000/docs`(Swagger API 문서) 및 `http://localhost:8000/health` 정상 응답 확인.

### 2-3. 터미널 2: 프론트엔드 대시보드 구동
```powershell
# [터미널 2]
cd frontend
npm run dev
```
- **확인**: 브라우저에서 `http://localhost:3000` 접속 후 우측 상단 `● 실시간 연결됨` 배지, 6석 좌석 배치도, 10종 센서/액추에이터 카드 표시 확인.
- 대시보드에서 `servo_door`(자동문) 열기 버튼을 누르면 5초 후 자동으로 닫힘으로 복귀하는지 테스트합니다.

### 2-4. 터미널 3: 비전 클라이언트 구동 및 1차 통합 테스트
> ⚠️ **웹캠 점유 체크**: Zoom, Teams, Discord, 브라우저 화상채팅, 카메라 앱 등 웹캠을 사용하는 프로그램을 먼저 모두 종료하세요.

```powershell
# [터미널 3]
cd vision
.\venv\Scripts\Activate.ps1
python main.py
```
- **확인**:
  1. 웹캠 영상 창에 6개 좌석 ROI 박스가 오버레이되는지 확인합니다.
  2. 키보드 숫자 `1`~`6`을 누르면 해당 좌석의 착석 상태(OCCUPIED ↔ EMPTY)가 토글되며 백엔드로 이벤트가 전송됩니다.
  3. 프론트엔드 대시보드(`http://localhost:3000`)의 좌석 배치도 색상이 실시간으로 변경되는지 눈으로 확인합니다.

## 3단계. 2차 개발 본격 진행 (핵심 고도화 과제)

1차 시스템이 정상 작동함을 확인했으면, 이제 팀원들과 2차 개발 과제를 분담하여 구현합니다.  
각 과제별 상세 프롬프트와 레퍼런스는 **[`docs/03-2차-완성-가이드-및-AI-프롬프트-핸드북.md`](03-2차-완성-가이드-및-AI-프롬프트-핸드북.md)**를 적극 활용하세요.

### 과제 A. 라즈베리파이 5 실기기 연동 (라즈베리파이 담당)
Mock 소프트웨어 시뮬레이터 대신 실제 라즈베리파이 5 하드웨어와 센서/액추에이터 기구물을 연동합니다.  
반드시 **[`docs/부록A-백엔드-라즈베리파이5-연동-인터페이스-가이드.md`](부록A-백엔드-라즈베리파이5-연동-인터페이스-가이드.md)**의 계약을 준수합니다.

1. **PC 로컬 IP 확인**: 백엔드가 실행 중인 PC의 PowerShell에서 `ipconfig` 실행 (IPv4 주소 확인, 예: `192.168.0.25`).
2. **라즈베리파이 환경 설정**:
   > ⚠️ **라즈베리파이 5 주의**: RP1 칩셋 특성상 `pip install lgpio` 시 C 컴파일 에러가 발생하므로 OS 기본 APT 패키지를 설치하고, 가상환경 생성 시 `--system-site-packages` 옵션을 사용합니다.
   ```bash
   # 1) 시스템 APT 패키지 설치
   sudo apt update && sudo apt install -y python3-gpiozero python3-lgpio

   # 2) 가상환경 생성 (시스템 패키지 상속) 및 활성화
   cd pi
   python3 -m venv --system-site-packages venv
   source venv/bin/activate

   # 3) 가상환경 내부 패키지 설치
   pip install -r requirements.txt
   ```
3. **`pi/.env` 수정**:
   ```
   BACKEND_URL=http://192.168.0.25:8000
   DEVICE_API_KEY=classroom_secret_2026
   ```
4. **배선 및 실행**: 전원을 끈 상태에서 안전하게 센서/액추에이터를 배선한 후 `python main.py` 실행.
5. **하드웨어 모드 전환**: `backend/.env`에서 `DEVICE_MODE=hardware`로 변경 후 백엔드 재시작.
6. **확인**: 웹캠 감지 또는 대시보드 버튼 클릭 시 라즈베리파이의 실제 서보모터, LED, 네오픽셀, 부저가 동작하는지 확인.

### 과제 B. 얼굴 인식 AI 파이프라인 연동 (영상인식 담당)
단순 키보드 시뮬레이션 및 사람 감지를 넘어, 실제 학생의 얼굴을 등록하고 식별하는 파이프라인을 구축합니다.
- `dlib` 대신 Windows에서 안정적인 **ONNXRuntime 기반 ArcFace/MobileFaceNet** 또는 **OpenCV DNN SFace**를 적용합니다.
- 학생 얼굴 임베딩 등록 기능 (`vision/register_face.py` 등) 구현.
- 웹캠에 등록된 학생 얼굴이 나타나면 백엔드의 `POST /api/v1/vision/events`로 `face_recognition` 이벤트를 즉시 전송합니다.

### 과제 C. 출결 및 좌석 상태 룰 고도화 (백엔드·프론트 담당)
- 학생이 얼굴 인증으로 입실하면:
  1. 출입문 서보모터 90도 개방 (5초 후 0도 자동 복귀)
  2. 선택된 좌석 번호 안내 및 출석 상태를 `PRESENT`로 갱신
  3. 교실 카메라의 실제 좌석 착석 ROI와 대조하여 `RESERVED`(예약/비어있음) / `OCCUPIED`(정상 착석) / `MISMATCH`(지정 외 좌석 착석) 판정
  4. 재실 인원이 1명 이상이면 교실 조명(릴레이) 자동 ON, 0명이면 자동 OFF
- 불꽃 센서 및 온습도 센서 위험 감지 시 관리자 대시보드 경보 모달 및 부저 연동.

## 4단계. 클라우드 배포 (선택/최종 단계)

로컬 연동이 완료된 후 어디서나 대시보드에 접근할 수 있도록 클라우드에 배포합니다:
1. **DB**: Supabase 프로젝트 생성 후 `backend/db/init.sql`을 PostgreSQL 문법으로 실행 (RLS 정책 적용).

3. **프론트엔드**: Vercel 프로젝트 배포 (`NEXT_PUBLIC_API_BASE_URL`, `NEXT_PUBLIC_WS_BASE_URL` 환경변수 지정).

## 🛠️ 막혔을 때 (FAQ & 트러블슈팅)

| 상황 / 에러 메시지 | 원인 및 해결 방법 |
|---|---|
| `ModuleNotFoundError: No module named 'backend'` | `backend/main.py` 최상단에 `sys.path` 주입 코드가 들어있으므로, 반드시 `cd backend` 후 `uvicorn main:app`으로 실행하세요. |
| Next.js 대시보드 `Hydration failed` 경고 | 서버와 클라이언트의 시간 차이 때문입니다. 시간 렌더링 태그에 `suppressHydrationWarning` 속성을 적용합니다. |
| `Control request failed: Failed to fetch` | 백엔드 서버(`http://localhost:8000`)가 켜져 있는지 확인하고, 브라우저 콘솔(F12)의 CORS 에러 여부를 점검합니다. |
| 웹캠 화면이 검은색으로 나오거나 열리지 않음 | 다른 프로그램(Zoom, Teams, 브라우저)이 웹캠을 점유하고 있습니다. 작업 관리자에서 해당 앱을 종료합니다. |
| 라즈베리파이에서 `401 Unauthorized` 에러 | `backend/.env`와 `pi/.env`의 `DEVICE_API_KEY` 값이 서로 다른 경우입니다. 두 파일의 키 값을 일치시킵니다. |
| 라즈베리파이에서 `Connection refused` | Windows Defender 방화벽이 8000 포트를 차단했을 수 있습니다. PowerShell 관리자 모드에서 인바운드 8000 허용 규칙을 추가합니다. |
| `Activate.ps1` 실행 오류 (`PSSecurityException`) | PowerShell에서 `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser`를 실행하여 스크립트 실행 권한을 부여합니다. |
| `mysql: command not found` | MySQL이 환경변수 PATH에 등록되지 않은 경우입니다. XAMPP phpMyAdmin 웹 UI의 [SQL] 탭에서 `init.sql`을 실행하세요. |
