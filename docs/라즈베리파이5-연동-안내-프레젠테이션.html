- 교무실은 가만히 앉아서 전체 상황을 기록하고 종합하는 두뇌예요.

대화 수단 배우기

REST API와 JSON: 교무실과 주고받는 포스트잇

외계어처럼 들리지만, 사실은 그냥 '규칙이 있는 쪽지'일 뿐입니다.

📬
REST API (심부름 규칙)
딱 2가지만 씁니다
1. GET (읽어오기)

"선생님, 제게 시키실 일이 적혀있나요?" 하고 상황판을 읽어오는 심부름

2. POST (제출하기)

"선생님, 시키신 문 열기 다 끝냈습니다!" 하고 완료 쪽지를 내는 심부름

📝
JSON (포스트잇 양식)
이름과 내용의 짝꿍

포스트잇에 아무렇게나 적으면 헷갈리니까, 중괄호 {} 안에 "항목": "내용"으로 단정하게 적기로 약속했습니다:

교무실에서 건네준 쪽지 
{
  "device_id": "servo_door",
  "desired_state": "OPEN",   // 목표: 문 열어라!
  "desired_value": { "angle": 90 }
}
💡

ELI5 한 줄 요약:

라즈베리파이는 GET으로 교무실 포스트잇(JSON)을 읽고, 다 하면 POST로 완료 포스트잇을 냅니다!

핵심 동작 원리

왜 반장이 3초마다 직접 찾아갈까? (폴링의 비밀)

"선생님이 반장을 직접 부르면 안 되나요?"에 대한 비밀을 풀어드립니다.

❓
선생님이 반장을 못 부르는 이유

학교나 집의 Wi-Fi 안에서는 라즈베리파이의 IP 주소가 수시로 바뀌고 방화벽 뒤에 숨어있습니다.

즉, 교무실(백엔드)은 반장이 지금 몇 반 몇 번 자리에 앉아있는지 알 수가 없어요!
그래서 교무실이 라즈베리파이로 먼저 전화를 거는 것은 불가능합니다.

🔄
해결책: 폴링 (Polling, 주기적 방문)

반장이 3초마다 교무실 문을 두드립니다:

1. "선생님, 저한테 시킬 일 있으세요?" (GET desired-state)
2. "어, 자동문(servo_door) 열어라!" (응답 받음)
3. 반장이 문을 열고는, "문 열었습니다!" (POST state 보고)
4. 3초 쉬고 다시 1번으로! (무한 반복)

⏱️ 3초 폴링 루프의 리듬 (코드 한눈에 보기)
while True:
  지시 = 교무실에_물어보기("servo_door")  # GET /desired-state
  if 지시 == "OPEN":
    print("🚪 [디버깅] 자동문 서보모터 90도 작동!")
    교무실에_보고하기("servo_door", "OPEN")  # POST /state
  time.sleep(3)  # 3초 쉬고 다시 질문하러 가기!
필수 준비물

딱 3가지만 맞추면 통신 100% 성공!

백엔드 친구와 이 3가지 단어만 똑같이 맞추면 모든 통신이 열립니다.

🔑
1. 출입증 (API Key)
X-Device-Api-Key

교무실 문을 열 때 보여주는 암호입니다.
백엔드와 내 파일(.env)의 글자가 점 하나까지 같아야 합니다.

CLASS_2026_09_05_v1_0_0
📍
2. 교무실 주소 (URL)
BACKEND_URL

백엔드를 켠 친구 PC의 로컬 IP 주소입니다.
주의: localhost는 나 자신을 뜻하므로 절대 쓰면 안 됩니다!

http://192.168.x.x:8000
🏷️
3. 내 부품 이름 (ID)
device_id

교무실 장부에 미리 등록된 정확한 이름표입니다. 철자가 틀리면 교무실이 못 알아들어요.

servo_door, reed_switch, dht_sensor ...
🤝

백엔드 담당 친구에게 딱 이 1마디만 물어보세요:

"다온아, 네 컴퓨터 ipconfig 쳐서 나온 IPv4 주소가 뭐야? 그리고 API 키는 뭐야?"

1단계 실습: 교무실에 첫 인사 건네기

5줄짜리 파이썬 코드로 "안녕 백엔드!"

내 라즈베리파이에서 백엔드까지 전파가 닿는지 30초 만에 확인해봅시다.

pi/01_ping_backend.py 
import requests

# 1. 백엔드 주소 (친구 IP로 변경하세요!)
URL = "http://192.168.0.100:8000/api/devices"

try:
    res = requests.get(URL, timeout=3)
    if res.status_code == 200:
        print("🎉 [성공] 교무실과 연결되었습니다!")
        print("등록된 디바이스 개수:", len(res.json()["data"]))
except Exception as e:
    print("❌ [실패] 교무실에 닿지 않아요:", e)
▶️

2단계 실습: 지시서(desired-state) 읽고 외치기

서보모터 대신 print문으로 가상 자동문 완성!

직접 버튼을 눌러 교무실이 지시를 내렸을 때 파이가 어떻게 반응하는지 체험해보세요.

headers = {"X-Device-Api-Key": API_KEY}
res = requests.get(f"{URL}/servo_door/desired-state", headers=headers)
desired = res.json()["data"]["desired_state"]

# 2. 지시가 OPEN이면 하드웨어 대신 print 출력!
if desired == "OPEN":
    print("🚪 [MG90S 서보모터] 위잉~ 문이 90도로 열립니다!")
    
    # 3. 교무실에 "문 열었습니다!" 보고하기 (POST)
    requests.post(f"{URL}/servo_door/state", 
                  headers=headers, 
                  json={"current_state": "OPEN"})
