## 1. 전시회 기획 배경 및 현황 진단

### 1.1 현재 구현 상태 (1차 완성)
- **파이프라인 구축 완료**: Windows PC 웹캠(YOLOv8 ONNX) → 백엔드(FastAPI) → 하드웨어 데몬(라즈베리파이 5 Mock) → 관리자 대시보드(Next.js WebSocket 실시간 동기화).
- **10종 디바이스/센서 규격 정의**: 서보모터(자동문), 좌석 LED, 네오픽셀, 부저, 릴레이(교실 조명), FHD 출입 웹캠, FHD 교실 웹캠, 리드스위치, 불꽃 센서, 온습도 센서.

### 1.2 전시회(시연) 관점에서의 한계 및 개선 필요성
1. **체험성 부족**: 팀원 6명(`202601`~`202606`)의 데이터만 하드코딩되어 있어, 관람객이나 심사위원이 직접 부스에서 자기 얼굴로 시스템을 체험해보기 어려움.
2. **짧은 시연 시간**: "얼굴 인식 → 문 열림 → 출석부 갱신"은 약 10초 만에 끝나, 관람객에게 깊은 인상을 남기기 어려움.
3. **스마트 교실 차별화 필요**: 단순 '출입 도어락'을 넘어, 실제 학교 교육 현장에서 필요한 **"수업 집중도/졸음 모니터링", "비상 화재 시 피난 대피 유도", "현장 음성 안내(TTS)"** 등의 고유 가치를 증명해야 함.

## 2. 전시회 맞춤형 5대 핵심 추가 기능 상세 기획

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                       스마트 교실 전시회 킬러 피처 구조                      │
├───────────────────────┬─────────────────────────┬───────────────────────────┤
│ 1. 관람객 즉석 등록   │ 2. AI 수업 집중도 감지  │ 3. 비상 대피 네오픽셀     │
│ (체험형 키오스크)     │ (MediaPipe 졸음/자세)   │ (피난 유도 러닝 라이트)   │
├───────────────────────┼─────────────────────────┼───────────────────────────┤
│ 4. AI 음성 비서 (TTS) │ 5. 스마트 에너지 세이빙 │ ※ 비상 대비 Fail-Safe     │
│ (현장 청각 피드백)    │ (빈 교실 자동 소등/환기)│ (단축키 치트 시뮬레이터)  │
└───────────────────────┴─────────────────────────┴───────────────────────────┘
```

### 💡 기능 1. [체험형] 관람객 '1일 게스트 학생증' 즉석 얼굴 등록 키오스크
- **기능 설명**: 관람객/심사위원이 태블릿이나 보조 모니터에서 이름과 희망 좌석을 입력하고 카메라를 3초간 응시하면 얼굴 특징점을 즉석 등록.
- **연동 흐름**:
  1. 관람객이 태블릿에서 이름 입력 ("홍길동") 및 좌석(3번) 선택.
  2. 웹캠 3초 캡처 → 백엔드 `/api/students/register`로 등록.
  3. 관람객이 미니어처 자동문 앞에 서면 얼굴 인식 성공 → "환영합니다, 홍길동 학생!" 음성과 함께 서보 자동문 오픈.
  4. 미니어처 3번 좌석의 네오픽셀이 무지개 웰컴 점등 후 초록색으로 점등.
- **예상 공수**: 약 1.5주 (백엔드 등록 API 1개 + 프론트엔드 모달 1개 + 비전 얼굴 임베딩 캐시).

### 💡 기능 2. [AI 비전 고도화] MediaPipe 기반 '수업 집중도 및 졸음/자세 이상 감지'
- **기능 설명**: 교실 천장 카메라가 6개 좌석 착석자의 머리 각도, 눈 감김(EAR), 엎드림 자세를 분석하여 수업 태도를 판정.
- **상태 정의**:
  - `ATTENTIVE` (집중): 정면 응시, 바른 자세 (좌석 LED 초록)
  - `DISTRACTED` (이석/산만): 5초 이상 고개 돌림 또는 자리 이탈 (좌석 LED 하늘색)
  - `DROWSY` (졸음/엎드림): 3초 이상 엎드리거나 눈 감김 (좌석 LED 노랑 점멸 + 경고음)
- **대시보드 표출**: 교사용 화면에 **"학급 실시간 집중도 지수 (예: 92%)"** 게이지 및 좌석별 주의 배지 표시.
- **예상 공수**: 약 2주 (Windows 비전 클라이언트에 MediaPipe 통합 + 이벤트 전송).

### 💡 기능 3. [비주얼 임팩트] 화재 비상 대피 유도 시스템 (스마트 피난 경로 라이팅)
- **기능 설명**: 불꽃 센서 감지 또는 비상 버튼 입력 시 교실 전체가 비상 탈출 모드로 전환.
- **연동 흐름**:
  1. 불꽃 감지 센서 반응 → 라즈베리파이 부저 비상 사이렌 울림.
  2. 서보모터 출입문이 100% 완전 상시 개방(Fail-Safe Open).
  3. 교실 바닥/복도의 네오픽셀이 **출구 방향으로 흐르는 녹색 러닝 라이트(피난 유도 화살표 애니메이션)** 재생.
  4. 대시보드 화면이 붉은색 비상 모드로 전환되며, 교실 카메라가 실시간 인식한 **[대피 완료 인원 / 교실 내 미탈출 잔류 인원]** 카운트다운 표시.
- **예상 공수**: 약 1주 (라즈베리파이 네오픽셀 시퀀스 데몬 + 대시보드 비상 모달).

### 💡 기능 4. [청각적 현장감] AI 음성 안내(TTS) & 현장 사운드 피드백
- **기능 설명**: 소음이 많은 전시장 환경에서 이벤트 발생 시 한국어 음성으로 명확한 상황 안내.
- **음성 시나리오**:
  - 입실 시: *"202601 김재민 학생, 출석 확인되었습니다. 1번 좌석으로 착석하세요."*
  - 미등록자 접근 시: *"등록되지 않은 외부인입니다. 출입이 제한됩니다."*
  - 비상 상황: *"화재가 감지되었습니다. 비상 유도등을 따라 신속히 대피하십시오."*
- **구현 방식**: 프론트엔드 브라우저 기본 내장 `window.speechSynthesis` (Web Speech API) 활용 (외부 API 비용 0원, 지연 시간 0초).
- **예상 공수**: 약 2일.

### 💡 기능 5. [스마트 에코] 재실 연동 에너지 세이빙 & 교실 실내 환경 자동 제어
- **기능 설명**:
  - 교실 내 재실자가 0명(EMPTY)으로 10초 이상 유지되면 조명(릴레이) 자동 소등 및 자동문 잠금 ('에코 락' 모드).
  - 온습도 센서(DHT11) 데이터를 분석하여 불쾌지수 기준치 초과 시 소형 팬(환풍기 모형) 가동.
- **예상 공수**: 약 3일 (백엔드 트리거 룰 조건문 추가).

## 6. 전시장 비상 대비책 (Fail-Safe)
- **전시장 네트워크 단절 대책**: 외부 인터넷이 끊겨도 작동하도록 내부 사설 공유기(로컬 IP 고정)로 백엔드와 라즈베리파이, 비전 PC를 묶는 로컬 오프라인 환경 구성.
- **센서/인식 오작동 대비 히든 치트키**: 비전 클라이언트의 키보드 단축키(`E`: 강제 입실, `1~6`: 좌석 상태 강제 순환, `F`: 화재 토글)를 비상 백업으로 유지하여 현장 돌발 상황에 100% 대처.
